# VR-освіта · освітня VR-платформа (лендінг + адмінка)

Платформа дистрибуції та ліцензування VR-уроків і віртуальних лабораторій для шкіл (Фізика, Хімія, Математика, Біологія, Історія, Астрономія, STEM) за ТЗ «VR-освіта», версія 4.0: розділ 2 (модель даних) і розділ 3 (адмінка `/admin`), плюс лендінг з пакетами й оплатою LiqPay.
Зроблено на основі коду Imersum XR (emuseum-code/imersum-xr) і адаптовано під ТЗ. Кабінет закладу освіти (`/cabinet`), API для окулярів (`/api/v1/vr`), лаунчер VR-Osvita Client і плагін VR-Osvita Gate будуть наступними етапами.

**Стек:** Laravel 13, Filament 5, PHP 8.3, PostgreSQL 16 (локально SQLite), dompdf (PDF), OpenSpout (XLSX/CSV), Cloudflare R2 (S3) для білдів.

| Журнали | Журнали | Журнал безпеки дій адмінів, журнал проведення VR-уроків (онлайн, офлайн, grace period). |

## Запуск локально

```bash
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan storage:link
php artisan serve                      # http://127.0.0.1:8000 і /admin
```

Демо-входи (пароль `ADMIN_PASSWORD`, за замовчуванням `password`):
`admin@vr-osvita.ua` (SuperAdmin), `methodist@vr-osvita.ua` (Методист), `finance@vr-osvita.ua` (Фінанси).

Тести: `php artisan test`.

## Відхилення від ТЗ

- Пароль у колонці `password` (стандарт Laravel), не `password_hash`; IBAN у `users.iban_treasury`, додано `users.city` для пошуку й масових операцій по громаді.
- Додано таблицю `lesson_builds` (історія білдів і бета-канал), `vr_lessons.released_at` (позначка NEW), `payments.package / subject_category` (пакети лендінгу) і службові поля, як в Imersum.

## Деплой

Push у `main` запускає GitHub Actions «Deploy»: образ збирається на GitHub, вантажиться на спільний VPS у `/opt/education-xr`, `docker compose` проєкт `education-xr` (edu-app, edu-queue, edu-web, edu-db Postgres 16). Caddy музейного порталу віддає сайт через `/opt/caddy-sites/education-xr.caddy`, мережевий псевдонім `eduxr-web`.
Секрети: `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`, `DOMAIN`, `ADMIN_PASSWORD`, `LIQPAY_PUBLIC_KEY`, `LIQPAY_PRIVATE_KEY`; необов’язково `R2_*` для Cloudflare R2.
Пакети й ціни лендінгу: `config/vrosvita.php` (`packages`) або env `PACK_LESSON_PRICE`, `PACK_SUBJECT_PRICE`, `PACK_SCHOOL_PRICE`.
